# Changelog

## [1.0.0] - 2026-10-02

First release.

- Two channels with a click-free switch: CLEAN (solid-state combo, Volume/Bass/Mid/Treble, Bright, spring reverb, 1x12) and DIRTY (British 50 W head, Preamp/Bass/Middle/Treble/Presence/Master, 4x12, optional mid-hump BOOST)
- Both cabs fitted to a reference recording: DIRTY within about 1 dB, CLEAN within about 1.5 dB
- Gate with an open/closed light
- Studio section: close mic to room mic, 2-inch tape saturation, and DOUBLE for a hard-panned double-track
- INIT button, knob shortcuts
- 4x oversampled, VST3 and Standalone for Windows 64-bit
